JSON: Jezik podatkov

Leto 2016. Splet se je začel hitreje vrteti. Potreboval sem način, kako hitro prenesti informacije, ne da bi obremenil celoten strežnik.

Odkritje JSON-a (JavaScript Object Notation) je bilo kot prehod na esperanto za računalnike. Pred tem so bili zapisi podatkov pogosto okorni in težko berljivi. JSON pa je bil preprost, lahek in neverjetno čitljiv – tako za ljudi kot za stroje.

Urejeno shranjevanje

Spoznal sem, da je JSON kot nalašč za konfiguracije in izmenjavo podatkov med frontendom in backendom. Nič več nepotrebne navlake, le čista struktura ključ-vrednost. Nenadoma so se vsi moji API klici zdeli veliko bolj logični.

{
  "projekt": "dervic.blog",
  "status": "aktivno",
  "jeziki": ["html", "css", "js"]
}

To je bila tista manjkajoča povezava v mojem znanju. Razumeti, kako serializirati objekte v JSON in jih kasneje pretvoriti nazaj v uporabno kodo, mi je odprlo vrata do gradnje bolj odzivnih spletnih aplikacij.

Standard današnjega spleta

Danes je JSON povsod. Od REST API-jev do nastavitev projektov. Enostavnost je njegova največja prednost. Naučil sem se, da v svetu razvoja niso vedno najbolj kompleksne rešitve najboljše – pogosto je prav tista preprosta, elegantna oblika zapisa tista, ki premaga vse ostale.

JSON je bil tisti košček sestavljanke, ki je vse moje projekte povezal v delujočo celoto.
